## Цель проекта

-Для класса Category сделать список товаров приватным атрибутом, чтобы к нему нельзя было получить доступ извне.
Для добавления товаров в категорию реализовать специальный метод add_product() в классе Category,
в который нужно передавать объект класса Product и уже его записывать в приватный атрибут списка товаров.

-Реализовать геттер, который будет выводить список товаров в виде строк в формате:
Название продукта, 80 руб. Остаток: 15 шт.

-Для класса Product создать класс-метод new_product, который будет принимать на вход параметры товара в словаре
и возвращать созданный объект класса Product.

-Для класса Product сделать атрибут цены приватным и описать геттеры и сеттеры. 
В сеттере реализовать проверку: в случае если цена равна или ниже нуля, выводить сообщение в консоль 
“Цена не должна быть нулевая или отрицательная”, при этом новую цену устанавливать не нужно.

-Написать тесты для функциональности.
